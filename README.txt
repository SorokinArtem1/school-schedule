Простой проект «Расписание занятий 1 класса»

Файлы:
- index.html — итоговая страница со всем расписанием (понедельник–суббота).
- part1.html — часть первого участника (понедельник–среда).
- part2.html — часть второго участника (четверг–суббота).
- style.css — общие простые стили для всех страниц.

Как посмотреть:
Откройте index.html двойным щелчком в браузере.

Как разделить работу для Git:
1. Создайте общий Git-репозиторий с index.html и style.css.
2. Первый участник создаёт ветку и добавляет/редактирует part1.html.
3. Второй участник создаёт отдельную ветку и добавляет/редактирует part2.html.
4. Каждый делает git add, git commit и git push.
5. На GitHub объедините обе ветки с помощью Pull Request и Merge.
6. В итоговый репозиторий добавьте index.html с общим расписанием.

Расписание и время условные, их можно изменить.
